# **App Name**: KineticFolio

## Core Features:

- Animated Hero Introduction: Displays dynamic, cycling professional titles with a typewriter effect, primary Call-to-Action buttons, orbiting tech icons, and a scrolling tech stack marquee.
- Hero Title Brainstorming Tool: An AI tool to suggest creative and professional titles or taglines for the Hero Section's animated text, tailored to the user's skills and experience.
- Site Navigation & Mode Toggle: A sticky navbar featuring glass-morphism blur, navigation links, a prominent 'Portfolio.' logo, and a dark mode switch button.
- Personal & Professional Bio: Showcases a detailed 'About Me' section with an illustrated avatar, background story, and key career statistics such as years of experience and projects completed.
- Work & Education Overview: Organizes professional work experience and academic achievements in a clean, two-column layout, highlighting job titles, companies, degrees, and institutions.
- Interactive Projects Gallery: An interactive grid of project cards, each with a screenshot, title, tags, a short description, and subtle hover effects like lifting and border highlighting.
- Direct Contact & Social Links: Provides a customizable contact form for inquiries (Name, Email, Message) and integrates links to various social media profiles (GitHub, LinkedIn, Twitter).

## Style Guidelines:

- Primary interactive and branding color: Cyan teal (#06B6D4) for a modern, bold aesthetic used on logos, CTAs, and interactive elements.
- Soft background color: Light desaturated blue (#E9F5F8) providing a calm and clean canvas, similar to the requested #EFF6FF, derived from the primary hue.
- Accent color: A subtle mint green (#4ABF85) for secondary interactive elements or highlights, chosen to be analogously contrasting with the primary color.
- Main font: 'Inter' (sans-serif) for all text elements, chosen for its modern neutrality and excellent readability across headlines and body content. Note: currently only Google Fonts are supported.
- Modern and minimalist icons from 'Lucide React' or 'React Icons' will be used, with an emphasis on outline styles for general elements and filled states for interactions (e.g., dark mode toggle, social media). Emojis will denote languages.
- Fully responsive layout designed for seamless viewing on both mobile and desktop. Sections feature distinct but fluid boundaries, including a sticky navbar with a glassmorphism blur effect, and strategic use of grid and flex layouts to organize content.
- Subtle yet engaging animations are key, including smooth scroll-triggered fade-in/slide-up effects for section transitions, continuous floating elements (translucent circles, tech icons), animated typing text in the hero, and interactive hover effects on project cards, all powered by Framer Motion.
